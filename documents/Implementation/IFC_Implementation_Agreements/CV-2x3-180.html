CV-2x3-180

Agreement on Color priorities in the Coordination View 

Based on          IFC2x3

Initiator            Official buildinSMART IFC2x3 CV2.0 certification programme

Effects              Coordination View 2.0

Date                    2013 09

Description:

To clarify the assignment priority of color to shape representations (refer to CV-2x3-131) by the following sequence:

    1. by one explicit color per solid;

        a. For Boolean results, by color assigned to Boolean result;

        b. If no color is assigned to the Boolean result, then the color from the 1st operand used;

        c. The IfcMappedItem shall NOT have a color assignment;

    2. if no color per solid is provided it must be from the assigned material color;

    3. if no material color than the color is defined by the assigned CAD Layer.

It is the responsibility of the importing application to display the correct color for shared geometries on different layers or with different material representations.
